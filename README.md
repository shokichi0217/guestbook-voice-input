# 御芳名帳 音声入力 Web App (Google Apps Script 連携)

タイピングが苦手なシニアの方でも、スマホやPCから簡単に芳名帳データを音声入力・登録できるWebアプリです。
Google Apps Script (GAS) を利用し、ご自身のGoogleスプレッドシートと直接連携して動作します。

---

## 🌟 特徴

- **シニア向けユニバーサルデザイン**: 文字が非常に大きく、押しやすいボタンレイアウトを採用。
- **音声認識 (Web Speech API) 搭載**: マイクをタップして喋るだけで自動で文字起こしされます。
- **便利なクイックボタン**:
  - `参列区分`（通夜・告別式）、`分類`（一般・会社・親戚）、`供花・供物`などは、1タップで選択可能。
  - `御香典の金額`も、よく使われる金額（3,000円、5,000円、10,000円、30,000円など）をボタンで即座に入力できます。
- **賢い自動整形**: 
  - 電話番号を口頭で喋ると、自動的に数字を抽出してハイフンを挿入します（例：「ぜろきゅーぜろ、いちにさん…」 ➔ `090-1234-xxxx`）。
  - 金額の音声入力時には、日本語の「さんぜん」「ごせん」「いちまん」といった発話を自動で `3000`, `5000`, `10000` などの数字に変換します。
- **確認・かんたん修正**: 送信前に確認画面で一覧が表示され、誤認識があった部分をタップするだけでそのステップに戻って修正が可能です。
- **音声フィードバック**: マイクの開始・終了時に「ピピッ」という電子音、登録完了時には美しいチャイム音が鳴り、画面を注視しなくても操作状態がわかります。

---

## 📂 ファイル構成

- `Code.gs` : Google Apps Script（GAS）側のサーバーサイド処理プログラム。
- `Index.html` : 音声認識、UI、効果音処理、送信ロジックを含むフロントエンド画面（単一ファイルで完結）。

## 🚀 導入手順（Googleスプレッドシート連携）

1. **Googleスプレッドシートを開く**:
   データを書き込みたいスプレッドシートを開きます。
2. **Apps Scriptを開く**:
   上部メニューの「拡張機能」 ➔ 「Apps Script」をクリックします。
3. **`Code.gs` の貼り付け**:
   デフォルトのコードをすべて消去し、リポジトリの `Code.gs` の内容をコピーして貼り付け、保存します。
4. **`Index.html` の作成**:
   左側の「＋」ボタンから「HTML」ファイルを追加し、ファイル名を「**`Index`**」（※一字一句同じにする必要があります）にします。リポジトリの `Index.html` の内容をコピーして貼り付け、保存します。
5. **ウェブアプリとしてデプロイ**:
   - 右上の「デプロイ」 ➔ 「新しいデプロイ」を選択。
   - 種類を「ウェブアプリ」に設定。
   - 「次のユーザーとして実行」を「自分（ご自身のアカウント）」、「アクセスできるユーザー」を「全員」に設定して「デプロイ」をクリック。
   - 初回デプロイ時はGoogleアカウントのアクセス承認を許可します（「詳細を表示」➔「安全ではないページに移動」をクリックして許可）。
6. **URLの取得**:
   発行された「ウェブアプリ URL」をスマホやPCのブラウザで開けば、すぐに音声入力を開始できます。
